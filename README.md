# Namcos12

**Tekken Tag Tournament online en Android**, con netplay por salas y relé UDP propio en Go.

Crea una sala con nombre, comparte el código y juega en línea contra otro teléfono. Incluye un renderer HD opcional y un menú propio dentro del juego.

---

## Características

- **Renderer HD (GLES3):** alta resolución con MSAA, elegible desde "Graficos HD". El renderer original sigue disponible.
- **Netplay por código de sala:** crear sala con nombre, código para compartir, lista de salas y partida rápida al azar — todo desde el menú del título.
- **Menú propio:** ARCADE / ONLINE / OPCIONES / CRÉDITOS, con letra propia.
- **Opciones (offline):** dificultad de la IA y vida ajustables.
- **Pantalla completa:** opción para estirar la imagen a toda la pantalla.
- **Juego libre:** sin monedas; START abre el menú.
- **Personajes extra:** Unknown jugable, más Tetsujin y Mokujin.
- **Rendimiento:** presentación a 60 Hz, baja latencia y prioridad del hilo del juego.

## Requisitos

- Android **arm64 (64 bits)**.
- Para jugar online, **ambos equipos deben tener la misma versión**.

## Instalación

1. Descarga el APK desde la sección oficial de **[Releases](https://github.com/Sx1ngth/Namcos12/releases/tag/v1.0.0)**.
2. Permite instalar desde orígenes desconocidos si tu teléfono lo pide.
3. Instala y abre.

## Cómo jugar online

1. En el menú del título entra a **ONLINE**.
2. **Crear sala** te da un código para compartir, o usa **Buscar partida** para una sala al azar.
3. El otro jugador entra con el código o desde la lista de salas.
